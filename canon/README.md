# Канон DAD v2

Этот каталог — **единственный источник правды** о том, какие уроки в датасете есть.
Всё остальное (`modules/`, `dataset/`, `routing/`) — производные представления и
должны собираться из канона, а не редактироваться по отдельности.

## Что здесь

| Файл | Роль | Руками? |
|:---|:---|:---|
| `skills.yaml` | таксономия: 6 навыков оси + 5 мета-навыков | да, это авторский текст |
| `overrides.json` | разметка: канонический id, навыки, алиасы, статусы, EN-заголовки | да |
| `lessons.yaml` | сгенерированные карточки 42 уроков | **нет**, генерируется |
| `mapping.md` | карта соответствия источников + отчёт о пробелах | **нет**, генерируется |

## Сборка

```bash
python3 scripts/build_canon.py     # без внешних зависимостей
```

Читает `sources/` и `canon/overrides.json`, пишет `canon/lessons.yaml` и
`canon/mapping.md`, печатает число уроков, баланс навыков и ошибки (битые ссылки
на модули/записи, неизвестные навыки). Ненулевой код возврата — если что-то
не сошлось, это пригодно для CI.

Исходники в `sources/` — копии обезличенных компиляций из Obsidian-хранилища:

| Файл | Уроков | Откуда |
|:---|:---:|:---|
| `sources/universal-ru.md` | 37 | «Мета-уроки. Универсальный аналитический инструментарий» |
| `sources/algorithms-ru.md` | 36 | «Алгоритмы диалектического анализа для сложных коммуникаций» |
| `sources/meta/deepseek/*.md` | 5 | мета-уроки 39–43, написанные DeepSeek |
| `sources/meta/gemini/*.md` | 7 | варианты уроков 31–36 от Gemini (см. `INDEX.md`) |

`Мета-уроки Самости.md` (2150 строк, исходные прецеденты с контекстами) **не
скопирован**: в нём имена, компания и рабочие эпизоды. Он используется как
справочник при написании `prompt`-ов, после обезличивания.

## Модель данных

```yaml
- id: snyatie-vs-umolchanie          # канонический slug, стабилен
  layer: corpus                      # corpus (DPO-ось) | meta (SFT, голос модели)
  status: merged                     # merged | draft | canon-only | review | meta-only
  title_ru: "…"                      # заголовок из компиляции
  title_en: "…"                      # авторский перевод, тело — Фаза 2
  skills: [distinction, contextual_reading]
  aliases: {algorithms: 7, universal: 8}
  modules: ["modules/03-hostile-reading/snyatie-vs-umolchanie.md"]
  records: ["03-hostile-reading-003"]
  fields: {context, idea, indicator, self_question, stop_phrase, …}
```

Статусы:

- `merged` — есть модуль в `modules/` и DPO-запись в `dataset/` (20 уроков);
- `draft` — модуль есть, DPO-записи нет (5 уроков, те самые незакоммиченные черновики);
- `canon-only` — есть только в компиляциях, в репозитории отсутствует (6 уроков);
- `review` — урок есть, но текст требует редактуры: вместо различения — пафос;
- `adapted` — текст переписан для публикации: манифест снят, различение и
  проверяемый индикатор сохранены (6 уроков: 31–36);
- `meta-only` — мета-урок модели, живёт в слое SFT, не в DPO.

Незнакомые метки полей сохраняются как есть, в кавычках (например,
`"Оптимальный диапазон для публикаций с модерацией"`): лучше потерять
единообразие ключа, чем содержание.

## Решения, принятые на Фазе 0

1. **Языки.** Русский — канонический: на нём написан источник и на нём держится
   культурная привязка (Хабр, эзопов слой, постсоветская политэкономия).
   Английский — язык релиза: сейчас `title_en` у всех 42 уроков, тело пар —
   Фаза 2. «Доступный» датасет без EN не индексируется на HF, но перевод
   эзоповых примеров должен быть адаптацией, а не подстрочником.
2. **Слои не смешиваются.** Уроки-инструменты (37) → DPO. Голос модели (5) → SFT.
   Варианты Gemini → не уроки, а свидетельство: 7 пересказов уроков 31–36.
3. **Номера — только алиасы.** `algorithms` и `universal` расходятся на +1
   начиная с 5-го урока; в репозитории своя нумерация (`00-context-001` и т.д.).
   Три нумерации одного урока — главная причина, по которой версии разъехались.
4. **PII.** В `sources/` только обезличенные тексты. Правило на будущее: любой
   новый урок проходит чек-лист (имена, компании, должности, узнаваемые эпизоды)
   до попадания в `sources/`.

## Что показала Фаза 0

- **42 урока в каноне:** 37 корпуса + 5 мета. Из них в датасете реально
  работает 20 — меньше половины.
- **Перекос по навыкам:** `distinction` — 19 уроков, `contextual_reading` — 13,
  а `artifact` — 4 и `hold_contradiction` — 3 (в корпусе). Датасет учит
  различать, но почти не учит **удерживать противоречие** и **отдавать артефакт** —
  то есть двум из шести заявленных навыков.
- **5 черновиков оказались не новыми уроками**, а исходными версиями
  уже опубликованных: `dialogue-as-construction` → Урок 2, `inverse-conway-maneuver`
  → Урок 4, `detecting-hidden-agitation` → Урок 9, `dialectical-cheat-sheet`
  → Урок 10, `Ловушка «вульгарной диалектики»` → Урок 13. Их не надо доделывать —
  надо связать с каноном и добавить DPO-записи.
- **Урок 38 отсутствует** во всех источниках, хотя урок 43 на него ссылается
  («Урок 38. Носитель Самости»). Либо он был переномерован в 43, либо потерян.
- **6 уроков помечены `review`** (31–36: MoE-психика, аутентичная экспертность,
  пластичность субстрата, прорыв через шаблон, субъектность из овеществления,
  цифровое ханжество). Это самые интересные тексты и самые рискованные: там
  диалектика подменяется манифестом. Их нельзя класть в `chosen` без редактуры,
  иначе модель выучит пафос вместо различения.
