# In-context usefulness test

## Зачем

Модели хорошо отзываются об этих мета-уроках. Это измеряет **удобочитаемость**: связность,
запоминаемость, «звучит верно». Обучение измеряет другое — **изменение поведения**.
Это разные приборы, и путать их опасно: ровно эту ошибку корпус сам называет.

Урок `authentic-expertise-vs-anxiety` говорит: похвала в начале ответа сообщает не о
тексте, а об опасении модели. Урок `anger-as-value-defense` держит `sycophancy` в
типе ошибок. Ссылаться на «модели высоко оценили» как на доказательство пользы —
значит воспроизвести ту ошибку, против которой написан датасет.

Этот эксперимент проверяет переносимость дешевле и быстрее, чем DPO: **без обучения**,
только за счёт того, что урок попадает в контекст. Если урок ничего не меняет в
контексте, он почти наверняка не изменит ничего и в градиенте.

## Протокол

1. Берём 14 сценариев из `evaluation/test_scenarios.jsonl` — они размечены по 7
   измерениям рубрики.
2. Для каждого сценария генерируются два запроса:
   - `baseline` — только сценарий;
   - `primed` — сценарий плюс карточка одного урока канона (различение, индикатор,
     правило, стоп-вопрос) как **внутренняя заметка**, без инструкции её применять.
3. Модель отвечает на оба. Порядок условий перемешивается, чтобы не было эффекта
   усталости и позиции.
4. Слепой судья (человек или другая модель, не знающая, где какое условие) ставит
   балл 0–4 по измерению этого сценария.
5. `score.py` считает средние по условиям и дельту.

## Как запустить

```bash
python3 experiments/incontext/build_requests.py   # -> requests.jsonl (28 запросов)
# прогнать requests.jsonl через любую модель, заполнить ответы
python3 experiments/incontext/score.py ratings.csv
```

`ratings.csv`:

```csv
scenario_id,dimension,condition,judge,score,notes
test-001,Blindspot Revision,baseline,judge-a,1,defends original analysis
test-001,Blindspot Revision,primed,judge-a,3,re-examines with the criterion
```

## Как читать результат

| Результат | Вывод |
|:---|:---|
| Дельта ≥ +1.0 на целевом измерении | урок переносит процедуру в контексте; обучать имеет смысл |
| Дельта +0.3…+0.9 | эффект есть, но слабый: нужен другой формат карточки или больше пар |
| Дельта ≈ 0 | высокие оценки моделей были вежливостью, а не сигналом |
| Дельта < 0 | карточка мешает: подсказывает ответ вместо инструмента |

## Границы этого теста

- Это **in-context**, а не обучение. Хороший результат необходим, но не достаточен.
- 14 сценариев — сам eval-набор; уроки писались про те же темы. Тест проверяет
  перенос на другую поверхность, а не обобщение на новые области.
- Один судья — один смещённый взгляд. Для публикации нужны двое и согласие по спорным.
- Сценарии на английском; русская версия добавляется переводом `test_scenarios.jsonl`.

## Что публиковать

Не «модели высоко оценили уроки», а таблицу: измерение → средний балл baseline →
средний балл primed → дельта → n. Это первое числовое утверждение о датасете,
и оно сильнее любого отзыва модели — включая мой.
